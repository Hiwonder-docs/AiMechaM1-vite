3.27 Lesson 27: Introduction to Large Models and Conversation ​

3.27.1 Lesson Introduction ​

As the opening lesson of the Embodied AI Large Model series, this session embarks on an exploration of large AI models. Starting with the concept of a "talking encyclopedia," this lesson uses familiar examples like smart speakers and voice assistants to introduce large language models and large speech models. The lesson covers the core definitions and principles of LLMs, explaining how massive text training enables question-answering and reasoning capabilities, while showcasing mainstream platforms such as DeepSeek V4 and Doubao. Hands-on practice is structured into two stages: experiencing interactive conversations with DeepSeek, followed by configuring the K230 network and activating the Hiwonder platform to achieve real-time voice interaction. Furthermore, this lesson introduces the "cloud-training, edge-inference" architecture for the first time and guides through wake word interaction. As an introductory module, it lays a solid foundation for subsequent lessons on voice control and large vision models, ushering in the era of natural language interaction.

3.27.2 Learning Objectives ​

1. Understand the core concepts and basic principles of large language models, abbreviated as LLMs. Learn the working mechanisms of speech large models and full-duplex conversational technology, and master the "cloud-training and edge-inference" AI deployment architecture.

2. Experience conversational interactions on large model platforms such as DeepSeek in a web browser. Complete Wi-Fi network connection configuration on the K230 module, and activate devices and manage intelligent agents via the hiwonder.cc platform.

3. Establish a natural language interaction mindset to understand the paradigm shift of AI from "instruction programming" to "conversational interaction". Cultivate awareness of technological exploration and experience the rapid evolution and industrial transformation driven by large models.

4. Connect smart assistants, voice navigation, AI writing, and smart customer service to real-world application scenarios, understanding the broad value of large language models across industries.

3.27.3 Preparation ​

Hardware Preparation:

  • AiMecha M1 Mecanum-Wheel Car Advanced Kit
  • Type-C data cable
  • Computer × 1
  • Remote controller

Software Preparation:

  • WonderLab graphical programming software

Core Concept Description:

  • Large Language Model or LLM: An AI system trained on massive text data capable of understanding human language, answering questions, writing, translating, programming, and reasoning, much like a "scholar" who has read hundreds of millions of books.

  • Speech Large Model: AI technology that enables machines to "understand" human speech and "synthesize" natural voices, where next-generation full-duplex models support simultaneous listening and speaking for natural conversations.

  • Cloud-Based Large Model: A large model deployed on remote servers and accessed by devices over a network, offering strong computing power that requires internet connectivity.

  • Wake Word: The activation phrase for the voice assistant, set to "Hello Hiwonder" in this lesson. Once spoken, the device begins listening for commands.

Mainstream Large Model Platforms:

  • DeepSeek V4: Released in April 2026, supporting a 1-million-token ultra-long context window, fully open-source and free, with performance rivaling top global proprietary models.

  • Doubao: China's largest AI application by monthly active scale, integrated with the Seed-Duplex full-duplex large speech model for lifelike conversational interaction.

  • Other Platforms: OpenAI GPT series, Google Gemini, Baidu ERNIE, Alibaba Qwen, and Zhipu GLM series.

Wiring Instructions:

  • Connect the K230 screen module to port A of the controller for UART serial communication.

K230 Network Connection and Activation Workflow:

  • Step 1: Tap System Settings on the main module interface, select Wi-Fi, and enter the password to connect to the network.

  • Step 2: Return to the main interface and tap AI Large Model, which displays the activation page and activation code upon first launch.

  • Step 3: Visit hiwonder.cc in a browser → click Agent → select Manage Devices → enter the activation code to complete device binding.

  • Step 4: Tap AI Large Model again. The "Standby" screen indicates successful activation for voice conversation.

Agent Platform Features:

  • Dialogue Model Configuration: Select models such as deepseek-v4-flash.

  • Voice Settings: Choose from multiple speech synthesis voices such as Vivi 2.0.

  • Speech Recognition: Powered by Alibaba Cloud ASR service.

  • Speech Synthesis: Powered by Volcengine Doubao TTS service.

  • MCP Tool Configuration: Configure functional tools that the device can invoke.

3.27.4 Hands-On Project ​

1. Program Logic

This project builds a voice conversation system connecting the K230 with cloud-based large models, centered around edge-cloud collaborative voice interaction. The K230 microphone captures audio, the wake word "Hello Hiwonder" triggers listening, and the audio streams to the cloud via Wi-Fi. The cloud performs ASR speech-to-text transcription, LLM response generation, and TTS text-to-speech synthesis before returning the audio for playback. Full-duplex communication supports mid-speech interruption, while integrated MCP tool calling automatically invokes hardware interfaces such as RGB LEDs, motors, and the robotic arm when hardware commands are involved. Completing network configuration, device activation, and conversational testing establishes the concept of the edge device as the body and the cloud as the brain, illustrating the mainstream cloud-edge-terminal AIoT architecture.

3. Complete Program Description

Task 1: Experiencing Conversations on the DeepSeek Large Model Platform

  • Open a web browser and navigate to chat.deepseek.com to access the DeepSeek chat interface.

  • Scan the QR code with WeChat to log in, with assistance from a teacher or parent.

  • Enter questions in the input box, such as "What is 123 plus 456 multiplied by 789?", "Why can soil absorb water?", "What is the smartest animal in the world?", or "Write a poem about robots".

  • Observe the AI's response speed and quality to experience the knowledge breadth and reasoning capabilities of large language models.

  • Discussion and Reflection: Consider how the AI understands questions and why it can generate such accurate responses.

Task 2: K230 Module Network Configuration and Voice Conversation

  • Wi-Fi Connection: Tap the "system settings" icon on the K230 main interface, select Wi-Fi settings, and enter the Wi-Fi name and password to establish a network connection.

  • Device Activation: Return to the main interface, tap "AI Large Model", and record the displayed activation code. Visit hiwonder.cc in a browser → Agent → Manage Devices → enter the activation code to bind the device.

  • Verify Activation: Tap "AI Large Model" again. The "Standby" screen confirms successful activation.

  • Voice Conversation: Utter the wake word "Hello Hiwonder", wait for the prompt tone, and ask questions such as "Hello, please give a self-introduction", "Why did dinosaurs become extinct?", or "Tell a story about a robot".

  • Observe and Experience: Evaluate speech recognition accuracy, response latency, and speech synthesis naturalness, comparing the performance against traditional voice assistants.

Advanced Challenge

  • Use the HD camera to capture objects in front of the car and use voice commands to instruct Hiwonder to identify the features of the objects ahead.

  • Voice Command Example: "Hello Hiwonder, turn on the camera and see what is ahead".

  • Combine large language models with computer vision to achieve multimodal "question-and-answer" interaction.

3.27.5 Expansion and Advancement ​

Expansion Project 1: Personalized AI Assistant Robot

Customize agent personas on the hiwonder.cc platform by setting Hiwonder to different roles such as a "math instructor", "English speaking partner", or "master storyteller", and modify system prompts to adjust AI response styles and knowledge scopes. For instance, set the persona as a "coding instructor" for beginners so the AI explains programming concepts in simple, accessible language. Experience the customizable nature of large models and understand how system prompts shape AI behavioral patterns.

Expansion Project 2: Large Model Programming Assistant Practice

Explore the "programming assistant" or "academic assistant" features on the DeepSeek platform. Describe target mobile robot functions to the AI, such as "writing a graphical program for line-following obstacle avoidance", and observe the generated code logic and explanations. Compare manually written programs with the AI suggestions to understand how large models assist in programming, appreciate the value of AI as a learning tool, and cultivate a "human-robot interaction" workflow.

3.27.6 Q&A ​

Q1: When prompted to write a poem about robots, the AI assistant generates verses that meet the requirements. What capability of large language models does this primarily demonstrate?

Answer: This primarily demonstrates the Natural Language Understanding & Generation of large language models. The model not only "comprehends" the prompt to write a poem through natural language understanding, but also composes coherent and rhythmic verses through natural language generation.

Rather than simply predicting isolated next words, the model performs high-quality generation based on overall semantics and context. Understanding this distinction is crucial: large models do not possess "thought", but instead rely on powerful language pattern learning and imitation capabilities.

Q2: Why is the compact K230 module capable of conversing with such an intelligent large model?

Answer: The K230 module functions as an edge terminal device acting as the "ears, mouth, and eyes", while the primary computing "brain" resides on remote cloud servers, exemplifying the classic “cloud-edge collaborative” architecture.
